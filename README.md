# Fablewood Audiobooks

Fablewood Audiobooks is an Android audiobook player built with Kotlin, Jetpack Compose (Material 3), and AndroidX Media3 (ExoPlayer).

## Requirements & Building

- **JDK 17** is required to compile the project.
- Open the repository root in Android Studio or build directly via Gradle / GitHub Actions.
- Run unit tests and assemble the debug APK:
  ```bash
  ./gradlew test assembleDebug
